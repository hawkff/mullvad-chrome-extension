# Mullvad extension for Chrome

A Chrome Manifest V3 port of the [Mullvad browser extension](https://github.com/mullvad/browser-extension), built with React and Bun. Type checking uses [tsc-rs](https://github.com/pingdotgg/ts-rust), an experimental Rust port of the TypeScript 7 compiler.

This is an unofficial project, not a Mullvad product. Development is in progress; there is no installable release yet.

The extension is a companion to the Mullvad VPN app. Its SOCKS5 proxies require a Mullvad VPN connection. It does not create a VPN tunnel.
